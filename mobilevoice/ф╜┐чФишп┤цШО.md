# 耳畔使用说明

适用：code54 / 0.3.23-preview。耳畔免费开源；模型、声音和云端额度由你自行配置。

## 安装与连接 Operit

1. 安装随包 APK。旧用户直接覆盖同签名版本，保留设置；不要先卸载或清除数据。
2. 在 Operit 内先发一句文字，确认所选聊天能正常回复。
3. 打开 Operit「工具 → 包管理 → ＋」，选择 `phone10-mobile-voice.js`，启用该包。JS 导入使用“包管理”，不是导入 .toolpkg 的“插件”页。
4. 首次接入运行 `setup`，确认返回 `SETUP_READY`。它创建/更新语音及取消工作流，不发送模型消息；`receive` 由工作流触发，不需要手动运行。
5. 打开耳畔「连接配置」，选择聊天窗口，再分别填写识别和语音合成服务。
6. 保存并使用，返回首页开始通话。按需授权麦克风、通知及悬浮窗；建议第一次用耳机测试。

### 旧用户更新插件

从 code50 或更早版本升级，需要同时更新 APK 和随包 JS；已有 code51-r2 插件的用户无需重复更新插件。code54 随包 JS 与 code53 相同。

先结束耳畔通话/只听回复，保存旧 JS。若 Operit 不允许覆盖同名工具包，在包管理移除旧 `phone10_mobile_voice` 条目，再导入本包同名 JS 并启用。使用已有工作流，运行一次 `setup` 核对/更新；不要手动另建第二套工作流。然后回耳畔重新开始。

## 语音通话与只听回复

- **语音通话**：识别你说的话并送入所选聊天，接收 AI 回复后朗读。
- **只听回复**：不启用麦克风。在所选 Operit 聊天里打字，耳畔读取新回复并朗读；兼容的 Operit 状态可提供回复增量，实际速度还取决于所选合成方式。
- 开启前的历史消息不补读；换聊天或声音时先结束会话，再重新选择。
- 关麦只暂停输入，当前回复继续；挂断结束语音会话。只听模式的“停止播放”保留监听，下一条新回复仍可朗读。
- 语音服务出错时，当前聊天文字仍继续接收；不自动重发聊天或切换其他付费服务。

## 选择语音服务

识别和合成可以使用不同服务，密钥在手机本地加密保存。

| 合成服务 | 方式 |
| --- | --- |
| 阿里云百炼 | 原生 CosyVoice WebSocket，持续追加文字 |
| 火山引擎 / 豆包 | v3 双向流式协议；资源、模型与音色需匹配 |
| MiniMax | 官方双向流式合成接口 |
| 模思 Mossland | HTTP 音频流；可选快速响应、语气连贯、整条合成 |
| ElevenLabs | Flash v2.5 WebSocket；v3 分段 HTTP 音频流 |
| Audio API 兼容 | HTTP PCM 接口，服务需实现相应合同 |
| 本机语音 | 连接自建兼容 WSS 网关与声音目录 |

识别可选百炼、火山、MiniMax、Moss 或 Audio API 兼容。平台提供接口不代表账号已拥有某个模型或声音的使用权限；请用自己的可用 ID。

### 检查连接

「检查连接」会读聊天列表，并调用所选语音接口进行静音识别/固定短句合成；不开麦、不播放，但会产生少量用量。只听模式不检查识别。额度不足时可以先保存配置，待可用后再验证。

### 声音方案

首页「当前声音」选择已有方案，或另存一份新方案。每份保存识别、合成、声音、Moss 语速及朗读方式。结束通话后再切换，下次会话使用新声音。声音目录刷新失败时保留已保存方案。

Moss 建议先比较「语气连贯」：首段较短、后续合段，减少独立生成次数。「整条合成」等本条回复真正结束，一次提交；等待更久，仍受服务长度及超时限制。客户端无法保证消除模型的音色变化。

## 字幕与后台

启用悬浮字幕后，支持的分段合成路线会按实际播放段落高亮并滚动。手动上翻暂停跟随，点“回到朗读”恢复。其他没有音频分段标记的路线仍显示文字；没有逐字时间戳。

按手机系统需要，允许耳畔和 Operit 后台运行。游戏声音共存受系统音频策略影响。长任务插件等待上限为30分钟、手机端额外10秒收尾；其他服务和 Operit 自身仍有各自限制，本版不是无限时长模式。

## 问题反馈

请提供耳畔版本、Operit 版本、手机系统、所选服务及“识别/聊天/合成/播放”哪一步异常。可以查看「最近语音状态」。分享截图前遮住密钥、私人地址与聊天内容。

本预览包的字幕和 Moss 新模式已做自动测试，尚未完成本次手机体验验收。语音由 AI 合成。
